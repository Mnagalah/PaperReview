# 作文批阅 · macOS MVP

导入英语作文照片，在中性灰工作台对照扫描增强页与忠实转写，再查看基础错误批注。识别、识别复核、语言审核分别显示进度；语法建议不改写原文。

## 启动

需要 Apple Silicon Mac、Xcode / Swift 6.2 或更新版本。目标系统 macOS 14+；当前开发机 macOS 27.2、24 GiB 内存。

```bash
./script/setup_models.sh
./script/start_models.sh
./script/build_and_run.sh
```

默认 **MiniCPM-OCR 1.0 未量化 F16 + Jev Q4_K_M + MiniCPM5-2B Q4_K_M**。五个权重及投影文件共 5,924,401,920 bytes（约5.924 GB），另需约16.5 MB的 llama.cpp b11960 运行时。本版按用户决定保留2B，不下载8B。

下载来自 OpenBMB 官方 ModelScope 发布源，集中保存到 `.local-models/`，可续传，不安装全局 Python/Homebrew 包。已有完整文件不重复下载。此前的 OCR Q4 文件保留供恢复，默认启动不使用它。

也可使用 Codex **Run** 按钮。应用入口位于 `dist/PaperReview.app`；双击打开后，可在“模型设置”启动本机模型。服务独立于窗口运行。为避免Documents文件提供程序改写应用签名，可运行构建保存在 `~/Library/Developer/PaperReview/Build/PaperReview.app`，`dist`入口链接到它；旧构建保留在对应的 `Previous/` 目录。

## 工作区

默认深色，模型设置内可改为跟随系统。左侧是作业与导入，中央是对照画布，右侧是基础审核；标题显示“作业批改 — 原文件名”。左右侧栏可收起，快捷键为⌘⌥S、⌘⌥I。审核标题将建议总数和更多菜单分开，批注按原文顺序先显示原词→建议，再给依据。

## 批阅

1. 从左侧作业列表上方**导入照片**（⌘O），或拖入 JPEG、PNG、HEIC、TIFF。先检查图片是否可读；相同文件内容即使改名，也会提醒已有作业，可查看或明确选择仍然导入。多张有效照片继续顺序处理，不被重复照片阻断。
2. 整页识别完成即显示文字；第二轮继续逐词独立识别，显示已处理词区数。连写/拆词由局部词组对齐，不因词数不等跳过整行。
3. 所有词区完成独立识别后，进行 Jev 局部候选比对和整页复核。逐词核验充分、稳定时直接进入基础审核；其余低分结果换用原色页或另一扫描强度，最多三次。不因未经校准的整页低分让正常作业机械重跑三轮，也不要求老师逐字确认才能继续。
4. 阶段栏右端选择**左右、上下或滑动对照**。滑动对照将照片与转写放在同一画布，拖动分界查看；三种方式共用滚动和缩放，支持触控板双指缩放，原缩放滑条保留。
5. “识别原文”旁的**疑义标记**开关控制紫色词区；它表示读字有分歧或没有可靠定位，不是已校准的错误概率。语言错误仍分别使用红/橙色；开关不改变文字、批注或审核数据。照片定位优先用词框，没有可靠词框才回退到行。
6. 点击顶部阶段栏的 **Jev** 查看各次分数和重新识别入口；不再从左下角进入。
7. 当完整逐词识别仍显示较多读字困难时，上方提示“**这份作业可读性较差**”，编辑入口改为“**核对原文**”。困难作业允许人工介入，正常作业不增加核对门槛；自动识别最多三次，不无限复试。
8. **忽略**只隐藏批注，可恢复；**编辑原文**是可选的 OCR 修正工具，保存会建立新版本并重新审核。
9. 列表右键**删除作业…**，或选中作业按删除键；确认后将本机作业副本移到系统废纸篓，导入来源文件不动。处理或加载中的作业暂不可删。
10. **导出**得到忠实原文 `.md`，或在原文后追加建议的 `.md`。不会将原文中的 `suny` 直接改为 `sunny`。

## 保真与坐标

- **照片**：方向归一、可靠纸边检测和透视校正、系统 `CIDocumentEnhancer` 去阴影与纸面增强。原文件始终保留。没有可靠纸边则保留完整画面，不按已识别文字裁掉漏检笔迹；不用硬二值化抹掉淡笔画。
- **字形**：阅读字号统一18pt，随左右共同缩放等比例变化。每页正文采用统一左边界，保留照片的物理换行与大致纵向位置。宽度不足时展开共同画布并横向滚动，不额外拆行，也不逐行拉伸字高或字宽。
- **位置**：MiniCPM 裸模型的 chat 文本不自带精确词框。本机 Vision 禁用语言纠错，提供词框和独立读字提示，再与 MiniCPM 全文对齐。少数行无法匹配时保留其他行的位置；失败行只保留大致显示位置，不猜测词框。部分连笔及词边界仍有误差。
- **第二轮**：每个检测词区独立送入 MiniCPM-OCR，不仅检查分歧词，也不设12词上限。保存词区、原文范围、独立读字、候选分数和选择依据；未定位原词、不可读词图均记录，不插入猜测文字。
- **选择**：两路独立读字一致的增字/漏字证据优先于整页常见词补全；同长度替换还需局部视觉支持。合词/拆词匹配不能吞掉一个完整原词，例如不能因只检测到homework的词框而将my homework替换成homework。其他替换使用保守 Jev 选择条件。
- **Jev**：同一词裁片与候选共用画布、等比例墨迹高度和留白，不把候选拉成同样长度。整页渲染独立于界面，版本 `native-plain-flow-v3`；词图版本 `word-ink-height-v1`。默认0.50是复识参考值。至少10个词区全部核验、定位覆盖至少95%、未解决词区不超过20%、跨图不可读/不稳定不超过10%时，可在完成Jev后直接继续。条件是工作流启发式，不是识别准确率或作文成绩。
- **审核**：仍由MiniCPM5-2B判断，只接收转写文本、不接收照片。系统英语词典提供待核实的拼写线索，不自动替换文字、不做语法判定。先生成最小纠错候选，再分别进行快速语法检查和最多512思考token的全文时间/语法检查；将候选与未改动原文做精确UTF16差分，自动确定原词和范围，不让小模型编造行号、引用或偏移。最后由同一个2B模型以最多512思考token逐项作`apply / keep_original`语义判断并分类。只显示接受的非冲突修改；中文说明是所选类别的固定说明，不冒充模型逐句推导。每篇最多四次批量模型请求，不为每个词重复调用审核模型；完整候选、判断和分阶段耗时保存在审核历史中。截断、缺项、矛盾判断或重叠修改均保留上次有效批注并允许单独重试。旧的行号/引用格式仍可读取。
- **可读性**：至少10个词区完整检查，其中一半不可读/不稳定时提示困难；至少四分之一存在同类困难，且Jev低于0.10或定位覆盖不足一半时，也提示。定位失败和低分不能单独触发，不使用语法错误数。这是待校准的困难提示，不是字符错误率或书写评分；旧记录缺证据时不倒推判断。

支持单张照片内的单页或清楚分置的左右双页；先读完整左页，再读右页。按页校正、识别及 Jev 复核，整次重试值取各页最小分。连续边栏行号与明确模板标签单独作为元数据，不进入学生正文；年份、数量与真实列表保留。

跨照片合并、任意弯曲书页的完整展平、涂改笔迹解释和规模化手写质量验证尚未完成。比赛固定使用既定三个模型，不引入其他 OCR 模型。

## 数据与恢复

作业默认保存在 `~/Library/Application Support/PaperReview/Assignments/`。每份独立保存原片、处理后原色页、扫描增强页、行/词几何、逐词核验记录、候选与审核批注。`text-structure-N.json` 提供页→行→词、坐标、源范围和证据状态；审核的源范围和候选ID作为元数据，与正文分开。参考答案不进入模型请求。

历史记录只升级扫描显示时，文字保持不变、行/词重新定位；旧图和记录另存 `structure-history/`。历史 Jev 分数标明原扫描版本，不冒充重新识别/评分；新识别只采用当前图像版本的分数。

模型请求只允许本机回环地址，禁用代理和远端重定向，不上传照片或文字。用户测试图及含原文记录放在被 Git 忽略的 `.local-tests/`，不混入公开合成 fixtures。

中断任务重开后保留已有结果，可继续或重试对应阶段。释放模型内存可在设置中停止，或运行：

```bash
./script/stop_models.sh
```

三个服务仅监听 `127.0.0.1:18499 / 18500 / 18501`，日志在 `.local-models/run/`。启停脚本只操作 PID、运行时路径和端口均匹配的本项目进程。启动脚本逐项等待健康接口返回 `status: ok` 后才报告就绪；进程退出或等待超时会返回失败和日志位置，不把“已创建进程”当作模型可用。服务连接失败不进入可读性判断。
