# 作文批阅 0.1.5

本地模型正式版，构建号 6，与当前日常版使用同一套功能代码。

- 识别存在分歧或缺少可靠照片定位的建议直接列出，并标注“可能识别有误”，不再藏在“未采用建议”弹窗内。
- 这些建议支持确认、放弃、恢复、撤销／重做和导出；已有作业无需重新识别即可显示。
- 重新审核立即反馈排队状态，轮到当前作业后自动进入处理；等待和失败重试期间保留已有建议。
- 空列表与已有结果共用液态圆点加载动画，固定提示位置，不推动列表。
- 排队期间禁用重复提交；模型无效引用在列表内说明具体原因，不猜照片坐标。
- README 使用用户审阅后的版本。

下载 `PaperReview-0.1.5-macOS-arm64.zip`，解压后将 `PaperReview.app` 放入“应用程序”，替换旧版。作业与模型保存在 Application Support，替换应用不会删除这些数据。

需要 Apple Silicon Mac，最低目标 macOS 14，建议 24 GB 内存。模型在本机运行；首次约 5.94 GB 模型与运行时需在设置中另行下载。ZIP 不包含模型或学生作业。

当前使用开发签名，尚未公证。首次被 macOS 阻止时，请确认来源后在“系统设置 → 隐私与安全性”批准打开。另一台 Mac 与最低目标系统尚未验收。
