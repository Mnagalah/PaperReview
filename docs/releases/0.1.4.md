# 作文批阅 0.1.4

本地模型正式版，构建号 5。

- 底部阶段条、分析状态和缩放保持同一行并靠右对齐；窄窗也不换排。
- 阶段文字长度变化时平滑伸缩，“分析中／分析完成”上下翻页切换；分析完成后阶段条继续显示。
- 删除中央与建议栏的常驻状态底栏；保存失败时仍提供重试入口。
- 未采用模型建议移至右栏分段控件下方，弹窗紧贴新入口。
- 左下服务状态直达本地服务，独立齿轮打开设置；设置窗口标题固定为“设置”。
- 修复窄窗缩放弹窗的百分比文字裁切；保留字号、缩放、Jev 详情及已批阅作业继续修改的入口。

需要 Apple Silicon Mac，最低目标 macOS 14，建议 24 GB 内存。模型在本机处理，约 5.94 GB 模型与运行时需在设置中另行下载；ZIP 不含模型或学生作业。

当前应用使用开发签名，尚未公证。首次被 macOS 阻止时，请确认来源后在“系统设置 → 隐私与安全性”批准打开。尚未在另一台 Mac 或最低目标系统验收。

API 在线版暂停，本次只发行本地模型版本。
