# 作文批阅 0.1.3

本地模型正式版，构建号 4。

- 原生三栏工作台、液态玻璃工具栏和响应式布局；窄窗保留文稿与批阅建议。
- 改进深浅色层级、滚动条和问题词标注，加入增强对比度配色。
- 支持确认／放弃建议、撤销／重做、批阅完成状态及持久保存，原文不改写。
- 右上操作依次为重新审核、完成批阅、分享；已放弃的问题通过垃圾桶入口查看。
- 处理阶段及逐词进度默认展开，等待状态使用液态双点；疑义标记默认关闭。
- 分享识别结果或识别结果（含批注）Markdown。

需要 Apple Silicon Mac，最低目标 macOS 14，建议 24 GB 内存。模型在本机处理，约 5.94 GB 模型与运行时需在设置中另行下载；ZIP 不含模型或学生作业。

当前应用使用开发签名，尚未公证。首次被 macOS 阻止时，请确认来源后在“系统设置 → 隐私与安全性”批准打开。尚未在另一台 Mac 或最低目标系统验收。

API 在线版暂停，本次只发行本地模型版本。
