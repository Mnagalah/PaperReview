# 工作区文案、进度与动作入口 · 2026-11-06

## 本轮实现

- 转写状态统一为“转写”。活动阶段默认展开到文稿底部，逐词阶段显示实际完成数和进度；窄窗将进度和显示控制换成两行，Jev 与暂停入口保留。
- 移除添加／编辑评语入口；旧数据已有评语仍可在阅读预览和导出中读取。
- 右栏等待状态采用用户指定 Amicro Liquid Dots 的双点分合外观，水平居中。Canvas 独立实现，30 fps / 1.6 秒循环；减少动态效果显示静态双点，非活跃场景暂停。原生分栏宿主显式传递 scenePhase。
- 来源列表去掉与原生选中态重叠的自绘整行背景。删除提示缩为文件名及移到废纸篓／保留原照片。
- “已发现问题”列出待判断问题，“已确认项”只包含确认的批注；操作为“确认／放弃”。已放弃记录保留并可重新确认，不删除既有决定。
- 右上原生工具栏顺序为重新审核、完成批阅、分享／导出。重新审核使用刷新图标，处理中或保存失败时禁用；不再埋入更多菜单或详情弹窗。
- 已放弃问题使用分段控件最右侧垃圾桶图标，空记录时禁用。其弹窗锚定图标；未采用建议弹窗锚定底部入口向上展开，不再锚定整栏。
- 导出菜单和默认文件名使用“识别结果”“识别结果（含批注）”。Markdown 章节使用“批注”“待确认批注”，移除批阅状态尾行；原始转写与旧评语不改写。

## 验证

### 原生应用实际交互

隔离预览内检查了选中行轮廓、确认／放弃、分段计数、撤销、导出菜单和精简后的删除确认（取消，未删除）。一次确认令已确认数增加，一次放弃不增加已确认数；验证操作已撤销。用户随后自行通过“重新确认”恢复了两条验证副本建议，未回滚用户后续操作。

底部未采用建议弹窗已出现在入口正上方；垃圾桶打开已放弃记录，箭头紧邻图标。最终原生工具栏可见顺序为重新审核、完成批阅、分享图标。
