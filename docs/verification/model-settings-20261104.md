# 2026-11-04 下载进度与模型管理

## 下载反馈

界面每 0.5 秒更新总进度、已下载量、速度、剩余量和预计时间。速度取最近 5 秒新增字节，已有文件及续传起点不计入本次速度；停滞时速度归零、预计时间暂不显示，状态改为等待服务器。下载期间使用确定进度条，不再只显示转圈。

脚本逐文件报告下载、重试、安装、完成和失败。断连自动重试，最终失败显示原因和“重试续传”。模型与运行时都保留临时文件，完整文件直接跳过。清单统一定义六个文件的路径和精确大小，总计 5,940,866,994 字节；下载来源和三模型配置未变。

## 删除与高级设置

“删除模型…”先检查文件占用，再确认当前目录和容量。确认后只把清单内的模型、对应未完成下载和就绪标记移到废纸篓；运行时、无关模型和作业不处理。移动失败会恢复已经移动的文件；恢复失败时保留暂存目录并显示位置。

高级设置整行可展开、折叠。标签固定左列，输入框统一左对齐；目录可通过原生文件选择器设置。复识参数单独分组，最多识别次数用 1–3 次分段控件。保存包含模型目录，反馈在按钮同一行；未保存的参数在折叠后仍保留。
