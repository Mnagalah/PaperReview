# 页、行、词结构与对照验证

实现起于2026-11-03，记录整理于2026-11-04。识别组合固定为MiniCPM-OCR F16、Jev Q4和MiniCPM5-2B Q4，未引入其他识别权重。

## 可采用的结果

- 横向左右双页通过页区域分开识别与复核，按完整左页→完整右页合并。真实双页探针的左页末尾与右页开头保持续写顺序，不再按两页全局y排序。
- 工作纸边栏编号和明确模板标签分离为元数据；遮除只作用于OCR/Jev输入，显示原图和原文件保留。编号识别不出来时保留框的几何，不编造数字。年份、数量和真正列表不套用删除规则。
- 真实编号照片的新模型输入和转写已不含侧栏编号。基础审核请求将定位ID和原文分为 `id/text` 字段，编号不作为作文语言审查对象。
- 保存页→行→词坐标、UTF16范围、独立读字、候选选择与分歧。词图第二轮覆盖全部检测区域；无法匹配的区域仍保存独立读字，不强行插入原文。
- 自然18pt字体随统一缩放变化；行宽不足时展开共同画布，不压字或额外拆行。每页共用一个正文左边界，保留物理换行和大致y位置。两页分别计算高度，右页短文不跟在左页底部显示。
- 左右、上下、滑动对照共用位置和缩放；用户已实际确认触控板双指缩放正常。疑义开关在识别原文工具行，布局切换在阶段栏最右侧。

## 有效证据与范围

私有照片、处理图和真实回复在 `.local-tests/20261103-layout/`，含 `numbered/`、`faint-final/`、`spread/`、`final-spread/`、`scan-final-numbered/`、`scan-final-faint/`、`final-unruled/`。原生工作记录在 `.local-tests/20261103-handwriting/assignments-v4/`。这些目录被Git忽略，不把学生照片写入公开合成样本。

Core覆盖双页顺序、分页续写、行片段分组、元数据排除、保留真实数字和学生错误、词对齐及跨页替换。macOS测试覆盖自然字高、窄视口完整物理行、每页共用左边界、双页高度、三布局共享坐标、缩放与词点击；测试日志另见2026-11-04工作台验证。

根代理通过CUA亲眼查看了真实手写工作台：自然字形、共同左边界、照片与转写、阶段栏布局切换、疑义开关及同步缩放。用户的双指手势确认是用户设备操作证据，不由程序触发缩放测试替代。旧的一次 `i` 落在 `finish` 内的误定位已用全词边界和唯一引用恢复修正；不能将它归因于照片输入语义审核。

## 扫描增强与形变边界

使用Apple公开文档分割/矩形检测、`CIPerspectiveCorrection`与文档增强；按左右页独立处理。只在可靠外纸边覆盖文字时裁切；模板框等参考四角采用 `crop=false`，已用框外红色像素回归验证保留内容。没有有效四角/横线时不作猜测形变。

最新版双页增强图已经人工查看：纸面更白、透视有改善，正文仍保留，但右页横线和书脊弯曲仍有残留。横线多项式补偿是本项目启发式，不是Apple公开的即用曲面扫描API，也不能称为所有书页完全展平。API核查见 `research/20261103-apple-document-scanning.md`。

显示升级只更新几何而保持文字版本；旧扫描、结构和词核验另存 `structure-history/`。旧Jev分数保留原扫描版本，不能当成新像素重新核验；完整重识别才产生新候选与分数。

## 仍未通过的质量项

整页OCR仍可能自动归正、漏掉冗词，未匹配词区尚无自动插入/删除恢复；已有 `I'm is…` 中漏 `is` 的反例。Jev对局部非标准拼写仍可能偏常见词。基础审核仍有误报、漏报与输出截断。结构、布局与正常执行通过不代表这几项识别/语义准确性通过。
