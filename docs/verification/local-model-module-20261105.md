## 原生手写全流程

使用用户此前提供的周末作文照片，在独立临时作业目录导入。从应用内启动三个模型后，点击失败阶段重试，自动完成一轮，无人工改文。

| 阶段 | 耗时 |
|---|---:|
| 整页 OCR | 8.28 秒 |
| 逐词识别与候选复核 | 70.13 秒 |
| 整页 Jev | 25.54 秒 |
| 基础审核 | 36.24 秒 |
| 合计（不含模型加载） | 140.20 秒 |

50/50 个物理词区完成独立读字。52 个转写词中 51 个有定位对应，10 个词区仍有读字分歧；检查完成不代表逐字无误。整页 Jev 约 0.2013，按已有稳定核验规则继续审核，没有强迫老师逐字确认。

原文保留 `wether`、`suny`、`feeled`、`have/go/finish/visit/help` 等写法。审核给出 12 条可定位建议，0 条定位拒绝、0 条因 OCR 疑义暂缓。没有把建议写回转写。

已实际检查：

- 忙碌阶段到完成的界面变化、12 条建议与自然字号；点击 `suny` 只框住照片中的对应词。
- 顶部 Jev 详情保留实际分数。
- 本机模型设置显示三服务就绪；高级设置地址、目录与识别参数完整。
- 下载确认显示官方来源、总量和目录；取消不下载。
- 退出后再次打开能显示原有作业和批注；未出现文稿授权提示。

命令行启动的服务曾在工具会话结束后不可达，应用如实显示连接错误；随后从原生设置启动成功并完成上述全流程。该失败未计作字迹差或识别低分。
