# 深浅色主题与可读性 · 2026-11-06

## 实现

原生三栏、窗口、工具栏与系统控件不变。主题调整按 Apple [Color](https://developer.apple.com/design/human-interface-guidelines/color)、[Dark Mode](https://developer.apple.com/design/human-interface-guidelines/dark-mode) 和 [Materials](https://developer.apple.com/design/human-interface-guidelines/materials) 的角色分层、双主题及辅助功能要求实施。

- 右侧工具面浅色提亮、深色保持层级，减少透明度或增强对比度使用不透明背景。
- 浅色滚动条改为中灰窄滑块，去掉重色轨道；仍是 NSScroller，只覆写部件绘制，不改拖动、键盘、辅助功能和系统滚动条显示偏好。深色及增强对比度使用系统绘制。
- 识别稿与普通阅读的浅色问题词统一为粗实线加淡色底纹。选中词仍用蓝色；疑义使用紫色点线，默认关闭。
- 自定义语义颜色集中到 WorkspacePalette，覆盖浅／深及增强对比度四种变体。照片维持原像素，词框在两套主题都使用深蓝，不把深色文字使用的浅蓝画到白纸上。
- 主按钮按下时压暗底色而不降低透明度；增强对比度加强选中项和按钮边界。原有主题偏好不重置。

## 检查

- 5 项定向测试通过：主题选项、批注属性、四套色板对比度、原生滚动条替换与位置保持、工具栏顺序及状态。
- 配色数值检查：类别／焦点／警告文字对文稿、画布和工具面均不低于 4.5:1；白色主按钮文字不低于 4.5:1；浅色滑块对工具面不低于 3:1。这是自定义色板的检查，不等同于整个应用的无障碍认证。
- 实际日常应用中切换浅色对照、深色普通阅读，再恢复浅色对照。已看到提亮的右栏、中灰滚动条、可辨识的下划线／底纹，以及深色原生菜单和文字层级。右栏向下、向上滚动均正常；作业仍为 13 个待确认问题、0 个确认项，没有确认、放弃或重新推理操作。
- 本系统手工构造高对比 NSAppearance 会回退为普通 Aqua／Dark Aqua。因此四变体测试直接调用界面共用的色板解析器；运行时通过系统增强对比度状态选择变体，没有把普通外观截图当成高对比系统验收。

未操作系统级增强对比度／减少透明度开关，未做 VoiceOver 朗读检查。系统材质与语义颜色沿用原生适配，自定义分支已加入数值和状态测试。
