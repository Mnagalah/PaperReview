# v1.2 界面方案的原生落地

日期：2026-11-06。范围：比赛版本地应用的 UI 和已确认的教师批阅交互，不涉及 API 版、模型替换或正式发布。

## 使用结果

按用户提供的 `PaperReview-UI-Design-v1.2.html` 与 `PaperReview-UI-v1.2.html`，将来源列表、连续工作面与建议检查器重新组织为原生 macOS 界面。保留照片原件、忠实转写、机器建议、教师判断四层内容，添加批注与保留原文都不会改写学生文字。

- 搜索以及全部／待批阅／已批阅筛选；完成后即使退出当前筛选，当前作业仍可阅读。
- 当前建议展开完整句子、原词、建议和原因；其他建议保持紧凑。正文与照片定位到同一问题词。
- 教师批注、保留原文、评语、完成时间单独保存，支持撤销／重做、处理历史与恢复待处理。
- 机器“分析完成”与教师“已批阅”分开；剩余建议必须明确选择保留后再完成。保存失败保留修改并提供重试，不给出已完成成功状态。
- 普通阅读、批注预览和原稿单独查看；左右、上下、叠图、共同缩放和平移保留。对照模式维持物理行，不新增软换行；普通阅读允许自然换行。
- 四组原生设置：通用、阅读与批阅、本地服务、高级。下载和启停明确作用于三个比赛模型；删除单独放入存储组并确认。
- 校对前保存旧版本；旧教师批注不因新 revision 被丢弃，失效位置标为待确认。没有当前匹配建议的历史记录不能以“恢复待处理”动作删除。

## 原生应用操作证据

验证应用使用独立测试目录 `.local-tests/20261105-ui-v12/isolated-qa/`，不在正式作业上进行添加、保留或完成测试。测试中未重新调用真实模型。

已通过 CUA 在实际运行的应用中观察：

1. 12 条建议添加批注后变为 11 条待处理，并自动选择下一条。
2. 保留原文后 11 → 10；撤销回到 11。原生 ⌘Z／⇧⌘Z 另行验证了撤销／重做。
3. 普通阅读点击 `suny` 选中右侧对应建议，显示一致的句子上下文。
4. 有剩余建议时出现明确确认；完成后变为已批阅、0 条待处理、12 条已处理，当前作业保持可见。
5. 保存评语使作业重新进入批阅中；重开后教师决定与评语仍在。
6. 上下对照使用同一作业；叠图分界 Home 到 0、End 到 100。原色／增强、比例控件与阶段详情入口保留。
7. 深浅色和四组设置在真实窗口中检查；本地服务显示“已安装，未运行”，没有把未运行误写成未安装。

实际 CUA 截图位于 `.impeccable/review/actual-macos-*.png`。这些截图含本机验证副本，已排除出 Git。

## 原生布局与数据测试

`WorkspaceSnapshotTests.swift` 在 NSHostingView 中渲染同文合成夹具，覆盖 1440×900、1280×800 的对照以及 1024×768 的浅深色阅读。窄窗直接按宽度收起侧栏。截图为内容区、2× Retina，不包含原生标题栏，也不是新一次 OCR 质量测试。

离线测试覆盖原文不变、教师决定持久化、完成确认、保存失败与重试、撤销／重做、旧记录迁移、阅读状态、UTF-16 句子锚点和导出。独立审阅发现的旧忽略恢复身份问题及失效历史误删问题，分别补了实际 Store 路径和变更 revision／同 revision 重审回归；结果见 `.local-tests/20261105-ui-v12/review-fixes.log`。最终完整离线运行见 `tests-delivery-final.log`：148 项测试，11 项真实模型或专用本机数据测试按既有开关跳过，其余通过；同一运行重新生成三档窗口的原生布局截图。另在真实验证应用中确认旧 revision 批注仍显示“位置待确认／历史记录”，不再提供会误删记录的恢复按钮，截图为 `actual-macos-stale-history-fixed.png`。

独立审阅及修复复核见 [收尾审阅](ui-v12-finish-review.md)。设计规范及机器可读颜色由 `DESIGN.md` 和 `.impeccable/design.json` 同步维护。
