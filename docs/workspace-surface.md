# 对照批阅工作台

模式：Operate；SwiftUI + AppKit 原生实现。用户指定 Codex 式中性灰，并以 Lightroom 为工作区结构参考；不引入摄影功能或装饰性科技效果。

## 方向

**老师先找到作业，再读照片和原文，最后处理批注。** 左侧来源列表、中央对照画布、右侧审核工具构成连续三栏；共用一个紧凑标题栏。标题为“作业批改 — 原文件名”，保留扩展名。

默认深色，设置提供跟随系统。灰阶用于外壳、选中态与操作；红橙区分语言批注，紫色只表示可关闭的OCR疑义。照片始终保留纸面颜色。

## 首屏与操作

- 左侧：作业总数、导入、轻量作业列表、底部模型状态；删除仍由右键或删除键触发可恢复的废纸篓操作。
- 中央：阶段栏及最右侧对照方式；照片模式、识别原文、疑义标记、复制与编辑在第二工具行；正文不附加说明标签。
- 右侧：60pt标题行内放标题、完整的“N 条建议”和独立更多按钮；批注先显示原词→建议，再给中文依据。
- 左右侧栏可隐藏，保留快捷键和原生分隔条；所有既有功能不因重排而消失。

正文统一自然18pt，每页统一左边界，保留物理换行。共同画布宽度不足时横向滚动，不拉伸字形；三种模式共享平移/缩放。滑动对照是同画布行级比较，不承诺逐字像素重合。
